# Gerenciador de Leitura de Mangás

Programa de terminal feito em Python para acompanhar a leitura de mangás. Os dados ficam salvos em um arquivo JSON, então nada se perde quando o programa é fechado.

## Funcionalidades

1. **Adicionar mangá:** cadastra título, volume atual, volume total e status de leitura.
2. **Listar mangás:** mostra todos os mangás cadastrados e quantos volumes faltam para terminar cada um.
3. **Remover mangá:** apaga um mangá escolhendo pelo número na lista.
4. **Sair:** encerra o programa, com tudo já salvo.

Todas as entradas são validadas, então o programa não quebra se o usuário digitar algo errado.
